## Cara Pakai

### Prerequisites
- Python 3.x
- pip

### Installation
1. Clone repository
2. Change directory
   - cd FinalsProject2
3. Create virtual environment
   - python -m venv venv
4. Activate virtual environment
   - Windows:
     - venv\Scripts\activate
   - Linux/macOS:
     - source venv/bin/activate
5. Install dependencies
   - pip install --upgrade pip
   - pip install pymupdf
   - pip install nltk
6. Run the project
   - python main.py
7. Select path
   - Linux example:
     - /home/user/Downloads/paper.pdf
8. Deactivate
   - deactivate
